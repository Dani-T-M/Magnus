# ✦ Magnus – eigenständige Handy-App

Läuft komplett auf dem Handy – ohne PC, auch offline. Daten bleiben auf dem Gerät.

## Einmal online stellen (kostenlos, ca. 10 Minuten) – GitHub Pages
1. Auf https://github.com ein kostenloses Konto anlegen.
2. Oben rechts **+ → New repository** → Name z. B. `magnus` → **Public** → *Create repository*.
3. **uploading an existing file** anklicken → alle Dateien aus diesem Ordner hineinziehen → *Commit changes*.
4. Im Repository: **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, Ordner `/ (root)` → *Save*.
5. Nach 1–2 Minuten ist Magnus erreichbar unter: `https://DEIN-NAME.github.io/magnus/`

(Die App-Dateien sind dann öffentlich abrufbar – **deine Daten nicht**, die liegen nur auf deinem Handy.)

## Auf dem Handy installieren
- **Android (Chrome):** Adresse öffnen → Menü ⋮ → **„App installieren“** bzw. „Zum Startbildschirm hinzufügen“
- **iPhone (Safari):** Adresse öffnen → Teilen → **„Zum Home-Bildschirm“**
- In Magnus: ⚙️ Einstellungen → **Benachrichtigungen erlauben**

Danach funktioniert Magnus auch ohne Internet.

## Daten vom PC übernehmen
PC-Magnus: Einstellungen → „Backup herunterladen“ → Datei aufs Handy schicken →
Handy-Magnus: Einstellungen → „📂 Backup laden“.

## Gut zu wissen
- Erinnerungen kommen zuverlässig, solange Magnus geöffnet oder im Hintergrund aktiv ist.
  Ist die App ganz geschlossen, melden sich fällige Erinnerungen beim nächsten Öffnen.
- Ab und zu **💾 Backup speichern** – wenn du den Browser-Speicher löschst, sind die Daten sonst weg.
- Optional echte APK für Android: die GitHub-Adresse auf https://www.pwabuilder.com eingeben → „Package for stores“ → Android.

## Updates
Neue Dateien einfach im GitHub-Repository hochladen (ersetzen) – die App holt sich das Update beim nächsten Öffnen.
